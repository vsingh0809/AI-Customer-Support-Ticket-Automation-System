# Cancellation Policy

## Before shipment

Customers may request cancellation while an order is still pending processing and has not entered shipment fulfillment.

## After shipment

An order that has already shipped generally cannot be cancelled through the normal cancellation flow. Support should explain the available return or refund process instead.

## Manual review

If the order state is unclear or the customer disputes the cancellation outcome, support should create a ticket for manual investigation.

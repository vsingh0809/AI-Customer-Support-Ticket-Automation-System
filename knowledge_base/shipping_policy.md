# Shipping Policy

## Estimated delivery

Estimated delivery dates are shown for an order when the logistics system provides them. The estimate is not a guarantee.

## Delayed deliveries

When an order is delayed, support should first check the order and available delivery status before giving a customer an update.

## Missing delivery

If an order is marked delivered but the customer did not receive it, support should verify the delivery information and create a ticket when additional investigation is required.
